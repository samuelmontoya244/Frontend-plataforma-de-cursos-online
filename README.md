🎓 Plataforma de Cursos Online - ITM
Este proyecto consiste en una plataforma web integral para la gestión y consumo de cursos en línea, desarrollada para la asignatura de Programación de Software (4to Semestre) en el Instituto Tecnológico Metropolitano (ITM).

La solución integra un backend robusto para la lógica de negocio y un frontend moderno e intuitivo para la experiencia del usuario, permitiendo la gestión completa del ciclo educativo digital.

🛠️ Stack Tecnológico
Backend
Lenguaje: Python

Framework: FastAPI

Persistencia: SQLAlchemy (ORM) con PostgreSQL

Autenticación: Seguridad basada en tokens JWT

Frontend
Framework: Angular 17+

Lenguaje: TypeScript

Diseño: Angular Material y CSS responsivo

Arquitectura: Organización modular (Core, Shared, Features)

📦 Módulos del Sistema
Inscripción: Flujo para que los estudiantes se registren en sus cursos de interés.

Evaluación: Creación y toma de exámenes para validar conocimientos.

Pago: Gestión de transacciones para el acceso a contenidos premium.

Material: Repositorio de recursos (documentos, enlaces y multimedia).

🔧 Instalación Local
Backend
Crear entorno virtual: python -m venv venv

Instalar dependencias: pip install -r requirements.txt

Ejecutar: uvicorn main:app --reload

Frontend
Instalar módulos: npm install

Ejecutar: ng serve

Acceder a: http://localhost:4200
